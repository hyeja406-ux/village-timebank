# 우리 마을 타임뱅크

이웃끼리 재능·물건·공간·시간을 나누는 방법을 체험하는 웹앱입니다.

## 사용 방법

1. index.html을 더블클릭해 브라우저로 엽니다. 별도 설치는 필요 없습니다.
2. ‘자원 찾기’에서 검색하거나 ‘내 자원 등록’으로 나눌 자원을 등록합니다. 이름에는 별명을 적어 주세요.
3. ‘활동 일정’과 ‘시간 기록’에서 예시를 살펴봅니다. ‘관심 있어요’는 안내만 표시하며 실제 연락은 하지 않습니다.

## 저장 방식

등록한 자원은 현재 브라우저의 localStorage에 저장되어 새로고침 후에도 남습니다. 다른 사람·기기·브라우저와 공유되지 않습니다. 브라우저 데이터를 지우면 등록한 내용도 지워집니다. 파일을 직접 열 때와 GitHub Pages에서 열 때의 저장 내용은 서로 다릅니다. 저장이 차단된 경우 화면에 오류 안내가 표시됩니다.

활동 일정과 시간 내역은 고정된 예시입니다. 시간 기록 입력·수정, 회원가입, 실제 주민 간 연결 기능은 없습니다. 예시 이름은 ‘이웃 A’, ‘이웃 B’로 바꿨습니다. 실명·전화번호·주소·계좌번호를 코드나 공개용 파일에 넣지 마세요.

## 파일 구성

- index.html: 첫 화면과 등록 창
- styles.css: 색상과 화면 배치
- app.js: 검색, 탭 전환, 등록, 브라우저 저장
- favicon.svg: 브라우저 탭 아이콘
- .nojekyll: 파일을 그대로 게시하기 위한 빈 파일
- .gitignore: 임시 파일과 설정·개인 데이터가 Git에 포함되지 않도록 하는 목록

원본은 React 기반 화면(app), 공용 화면 부품(components), Cloudflare·Sites 설정과 서버 예제를 포함했습니다. 공개용 버전은 HTML/CSS/JS만으로 다시 구성했으며 원본의 서버·Sites 설정은 포함하지 않았습니다. 모든 웹앱 파일 경로는 상대 경로입니다. 빌드 명령은 필요 없습니다.

## GitHub Pages에 올리기

공개용 ZIP을 압축 해제하고 안의 파일을 저장소 맨 위에 올리세요. index.html이 하위 폴더에 들어가지 않도록 하세요. 저장소의 Pages 게시 폴더는 파일을 올린 브랜치의 맨 위(root)로 지정하면 됩니다. .nojekyll과 .gitignore도 함께 포함하세요. 이 작업은 게시용 파일 준비까지만 수행했으며 실제 GitHub 업로드는 하지 않았습니다.

work와 outputs는 작업용 폴더이며 사이트 파일이 아닙니다. 원본 ZIP은 공개 저장소에 올리지 마세요. .gitignore는 Git으로 추가할 때 적용되므로 브라우저에서 직접 올릴 때도 공개용 파일만 선택하세요.
